# Сайт психолога Наталі Коваленко

Домен: natalyakovalenko.com.ua

## Як це працює

- **GitHub** — сховище. Усі зміни сайту робляться тут.
- **Cloudflare Workers** — публікує сайт. Після кожного коміту в гілку `main` сайт оновлюється автоматично приблизно за хвилину.
- **GitHub Pages** (lunaobitaema.github.io/nata) — запасний перегляд. Власний домен у GitHub Pages не вказувати.

У панелі Cloudflare нічого не редагувати: наступна публікація з GitHub перезапише зміни.

## Файли

- `index.html` — лендинг курсу «Перезавантаження стосунків» (варіант дизайну 10)
- `oferta.html`, `privacy.html`, `refund.html` — чернетки юридичних сторінок, потрібна перевірка юристом
- `img/` — фото (`author-2.jpg` — автор, `og.jpg` — превʼю для соцмереж)
- `favicon.svg` — значок вкладки
- `wrangler.jsonc` — налаштування Cloudflare Workers
- `.assetsignore` — службові файли, які не публікуються

Фото пар і мініатюри поки підвантажуються з Unsplash (автор Vitaly Gariev). Перед запуском їх варто завантажити в `img/`.

## Секрети

Токен бота, ключі WayForPay та інші секрети зберігаються лише в Cloudflare (Worker → Settings → Variables and Secrets). У репозиторій їх не додавати: репозиторій публічний.

## До запуску

- Сторінки закриті від пошуковиків (`noindex`). Прибрати перед запуском.
- Заповнити юридичні сторінки.
- Підключити оплату (дві кнопки: європейська картка і гривнева) і Telegram-бота.
