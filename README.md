# Лендинг курса «Перезавантаження стосунків»

Статический сайт для GitHub Pages. Сборка не нужна.

## Файлы

- `index.html` — лендинг
- `oferta.html`, `privacy.html`, `refund.html` — черновики юридических страниц
- `img/hero.jpg`, `img/author.jpg`, `img/og.jpg` — фото автора (первый экран, блок «об авторе», превью для соцсетей)
- `favicon.svg` — значок вкладки
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages

## Как выложить на GitHub Pages

1. Создайте репозиторий на github.com.
2. Загрузите в корень репозитория все файлы из этой папки, включая папку `img` и файл `.nojekyll`.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Source: Deploy from a branch, ветку `main`, папку `/ (root)`. Нажмите Save.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Что заполнить

В конце `index.html` есть блок `CONFIG`:

- `price` — цена, например `'990 грн'`
- `oldPrice` — старая цена, только если курс действительно продавался дороже
- `payUrl` — ссылка на оплату WayForPay
- `legal` — строка с данными ФОП и контактами для подвала

Пока `payUrl` пустой, кнопка в блоке с ценой показывает сообщение, что оплата не подключена.
