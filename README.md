# Сайт психолога Наталі Коваленко

Домен: natalyakovalenko.com.ua

## Як це працює

- **GitHub** — сховище. Усі зміни сайту робляться тут.
- **Cloudflare Workers** — публікує сайт. Після кожного коміту в гілку `main` сайт оновлюється автоматично приблизно за хвилину.
- **GitHub Pages** (lunaobitaema.github.io/nata) — запасний перегляд. Власний домен у GitHub Pages не вказувати.

У панелі Cloudflare нічого не редагувати: наступна публікація з GitHub перезапише зміни.

## Файли

- `index.html` — тимчасова переадресація з кореня на сторінку курсу (основну роботу виконує `_redirects`)
- `_redirects` — правило Cloudflare: `/` → `/perezavantazhennya/`
- `perezavantazhennya/index.html` — лендинг курсу «Перезавантаження стосунків» (варіант дизайну 10)
- `perezavantazhennya/dyakuyu.html` — сторінка після оплати з кнопкою «Відкрити курс у Telegram»
- `promo/index.html` — оплата особистої консультації зі знижкою для учасниць курсу. З сайту посилання немає: персональний одноразовий промокод (діє 30 днів) і кнопка «Дізнатися більше» приходять у бот разом із лекцією 3. Ціни в євро, оплата в гривнях за курсом НБУ. Після оплати Наталя отримує сповіщення в боті. Тексти й ціни — `src/course.json` → `consult`
- `promo/dyakuyu.html` — сторінка після оплати консультації
- `src/worker.js` — сервер: оплата WayForPay, Telegram-бот, розклад лекцій, адмінка
- `src/course.json` — **тексти бота, ціни, назви лекцій, розклад** (змінювати тут)
- `src/admin.html` — інтерфейс адмінки (`/admin`)
- `oferta.html`, `privacy.html`, `refund.html` — чернетки юридичних сторінок, потрібна перевірка юристом
- `img/` — фото (`author-2.jpg` — автор, `og.jpg` — превʼю для соцмереж)
- `favicon.svg` — значок вкладки
- `wrangler.jsonc` — налаштування Cloudflare Workers
- `.assetsignore` — службові файли, які не публікуються

Фото пар і мініатюри поки підвантажуються з Unsplash (автор Vitaly Gariev). Перед запуском їх варто завантажити в `img/`.

## Секрети

Токен бота, ключі WayForPay та інші секрети зберігаються лише в Cloudflare (Worker → Settings → Variables and Secrets). У репозиторій їх не додавати: репозиторій публічний.

## До запуску

- Сторінки закриті від пошуковиків (`noindex`). Прибрати перед запуском.
- Заповнити юридичні сторінки.
- Вказати реальні мерчанти WayForPay (зараз можна тестовий режим `WFP_TEST=1`).
- Звірити суму в гривнях у `src/course.json` (`prices.uah`).
